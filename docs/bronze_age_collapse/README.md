# Bronze Age Collapse WikiGraph

Research-facing history/humanities demo for a multi-causal collapse debate.

This demo is useful as the lighter entry route before the denser K-Pg source-audit demo:

- multiple composition maps;
- wiki-page-like nodes;
- claims, evidence, narratives, and open questions;
- falsification conditions for competing collapse hypotheses.

It is less source-audited than the K-Pg package, so it should be presented as an accessible research-demo / humanities-demo, with K-Pg following as the stricter source-audit example.

## Files

- `demos/bronze_age_collapse/index.html`: standalone interactive HTML with UTF-8 metadata.
- `data/legacy_cases/bronze_age_collapse/bronze_age_collapse_wikigraph.json`: extracted graph data.

## Suggested Positioning

Use this to show that the same epistemic graph pattern can represent humanities and historical debates where causes are multi-factor, sources are heterogeneous, and narrative simplifications are common.
