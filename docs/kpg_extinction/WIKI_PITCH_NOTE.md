# Wiki/Wikimedia Pitch Note — K–Pg Demo

**Safe framing:**

> This is not a Wikipedia replacement. It is a dispute-visualization aid that helps editors see claims, evidence, counterevidence, source quality, and weighting.

## Why editors might care

Wikipedia articles often compress complex disputes into prose. WikiGraph shows the structure underneath the prose:

- which claims are consensus-level;
- which claims are minority or overclaim risk;
- which evidence supports or weakens each claim;
- which sources are reviews, primary studies, models, or policy pages;
- where a disputed topic needs better wording rather than a louder conclusion.

## What to show first

Use the `Wikipedia-facing source weighting demo` composition map.

The strongest demonstration is that the graph does **not** make all claims look equal:

- `claim:impact_primary` is Tier A;
- `claim:deccan_contributor` is Tier B;
- `claim:impact_deccan_interaction` is Tier C;
- `claim:deccan_sole_established` is Tier X / parked overclaim;
- `claim:impact_only_no_background` is also weakened, showing that majority-side oversimplification is handled too.

## One-line product message

**WikiGraph makes article disputes inspectable without bypassing the editorial process.**
